### Finance Tracker | Minimal

Минималистичный менеджер личных финансов. Приложение позволяет не только фиксировать расходы, но и автоматически группирует их по категориям, рассчитывает общую сумму и сохраняет данные в локальное хранилище.

[Живое демо (GitHub)](https://narrativeee.github.io/finance-tracker/)  
[Зеркало на Netlify](https://finance-tracker-narrativiii.netlify.app)

### Особенности:
* **Smart Categorization:** Автоматическая группировка трат по типам (Еда, Транспорт, Хобби и др.) с визуальным разделением.
* **Price Calculation:** Ввод количества и цены за единицу с автоматическим расчетом итоговой суммы позиции.
* **Keyboard Navigation:** Полная поддержка ввода через `Enter` — быстрое переключение между полями без использования мыши.
* **Custom Modals:** Стилизованное окно подтверждения удаления вместо стандартных системных уведомлений.
* **Persistent Storage:** Все данные сохраняются в `LocalStorage` и доступны после перезагрузки страницы.

### Технологии:
* **HTML5** - семантическая разметка и кастомные модальные окна.
* **CSS3** - Dark Minimal дизайн, анимации появления (`Keyframes`), эффект размытия (`Backdrop-filter`).
* **JS (Vanilla)** - сложная логика группировки через `Array.reduce()`, управление фокусом и работа с событиями клавиатуры.
* **LocalStorage API** - хранение и синхронизация базы расходов.
